# Sony HXR-MC2500 LANC/REMOTE Research

## Executive Summary

The HXR-MC2500 is a Sony NXCAM shoulder-mount AVCHD camcorder with a **standard 2.5mm LANC jack** labeled "REMOTE". Official Sony accessories (RM-1BP) and third-party LANC controllers (AODELAN ZC-1/ZC-3/ZC-4) explicitly list the MC2500 as compatible. The camera uses standard LANC protocol, not a proprietary Sony professional variant.

---

## 1. Operating Manual on REMOTE Jack

### Manual Description (Page 8)
> **A REMOTE jack** — The REMOTE jack is used for controlling the playback of video devices and peripherals connected to it.

**Source:** [Sony HXR-MC2500 Operating Manual, Page 8](https://sony.com/electronics/support/res/manuals/4558/45589301M.pdf)

### Important Notes from Manual
- The manual also states: "It may take several seconds for the video light to turn off after you turn off the power of the camcorder with a remote controller (sold separately) connected to the REMOTE jack."
- This confirms the REMOTE jack is intended for wired remote control, not just playback devices.

**Source:** [ManualsLib - Sony HXR-MC2500 Operating Manual](https://manualslib.com/manual/950017/Sony-Hxr-Mc2500.html)

### Menu Settings
**NO dedicated "Remote Commander Enable/Disable" or "CTRL for LANC" menu option** was found in the MC2500 manual. Unlike some Sony cameras that have specific remote control settings in the menu, the MC2500 appears to accept LANC commands whenever a controller is connected.

The OTHERS menu contains:
- INITIALIZE
- BEEP
- REC LAMP
- Various other settings

**No REMOTE or LANC-specific enable/disable toggle documented.**

**Source:** [ManualsLib - Sony HXR-MC2500 (OTHERS) Menu, Page 77](https://manualslib.com/manual/950017/Sony-Hxr-Mc2500.html?page=77)

## 2. Official Sony Wired Remotes for MC2500

### RM-1BP LANC Remote Commander
Sony's official recommendation for the HXR-MC2500:
- **Product:** RM-1BP LANC Remote Commander
- **Functions:** REC START/STOP, FOCUS button, REC REVIEW, Zoom lever (3 speed ranges)
- **Connection:** 2.5mm stereo mini-mini jack
- **Compatibility:** "Any Sony HDV and DVCAM camcorders that have a LANC port"

**Source:** [Sony Pro RM-1BP Product Page](https://pro.sony/en_GB/products/camera-remote-controls/rm-1bp)

### RM-30BP Remote Commander (Newer)
- **Product:** RM-30BP (successor to RM-1000BP)
- **Functions:** Lens control (focus, iris, zoom), recording/display, shutter speed, white balance, 6 assignable buttons, multi-camera control (up to 3 cameras)
- **Compatibility:** Listed as compatible with HXR-NX5R, PXW-FS7 v4.0+, and plans for "other Sony camcorders"
- **Note:** The MC2500 is listed in AODELAN compatibility charts for RM-30BP replacement remotes

**Source:** [Sony Professional Camcorder Family Brochure](https://pro.sony/s3/2018/09/11131853/procam-family-brochure.pdf)

### RM-VPR1 Remote Commander
- Uses Multi Terminal or REMOTE Terminal
- Basic recording functions: power on/off, video/still recording, zooming
- **Note:** "May not be compatible with all cameras" - requires checking Sony website

**Source:** [Sony RM-VPR1 Manual](https://www.sony.com/electronics/support/res/manuals/4465/73c9fca4d670d142290d964339cc1e5f/44657460M.pdf)

## 4. Standard LANC vs Sony "Professional Remote" Protocol

### MC2500 Uses Standard LANC Protocol

The HXR-MC2500 uses **standard LANC (Control-L) protocol**, not a proprietary Sony professional variant.

**Evidence:**
1. The specs list: **"Remote: Stereo mini mini jack ø2.5 mm (x1)"** - standard LANC connector
2. Official RM-1BP is designed for "any Sony HDV and DVCAM camcorders that have a LANC port"
3. Third-party LANC controllers work with MC2500
4. No mention of special protocol requirements in any documentation

**Source:** [Sony Pro HXR-MC2500 Specs](https://pro.sony/s3/cms-static-content/uploadfile/68/1237493107968.pdf)

## 5. 2.5mm LANC Jack Pinout

### Standard LANC 2.5mm TRS Pinout (Device Jack View)

```
        TIP (1)   = LANC Signal (bidirectional data)
        RING (2)  = +Vdc (5-8V power output, ~100mA max)
        SLEEVE (3) = Ground
```

**Verified Pinout:**

| Pin | Signal | Description |
|-----|--------|-------------|
| TIP (L/1) | LANC | Bidirectional serial data line |
| RING (R/2) | +Vdc | +5 to +8V power (unregulated, depends on battery) |
| SLEEVE (3) | GND | Ground |

**Sources:**
- [PinoutGuide - Sony LANC Interface](https://pinoutguide.com/DigitalCameras/sony_lanc_pinout.shtml)
- [Wikipedia - LANC](https://en.wikipedia.org/wiki/LANC)
- [Boehmel.de - LANC Protocol](http://www.boehmel.de/lanc.htm)

### Power on Tip (Ring) - Required?

**The 5V power on Ring is OUTPUT from the camera, NOT input required for LANC to work.**

The camera provides power to the remote controller. If building a DIY controller:
- **DO NOT** need to provide 5V to enable LANC
- **CAN** draw up to ~100mA from the camera's power output
- Power is unregulated (5-8V depending on battery state)

**Power-On via LANC:**
- On Mini-DIN connectors: Pin 3 to GND for >140ms powers on
- On 2.5mm jack: Connect LANC signal to GND for >140ms to power on (some models)

**Source:** [Boehmel.de - LANC Connections](http://www.boehmel.de/lanc.htm)

## 6. Known MC2500 LANC Behavior and Issues

### General LANC Behavior

1. **Commands require 3-4 consecutive frames** to be accepted
2. **Frame rate:** 20ms for PAL, 16.6ms for NTSC
3. **Protocol:** 9600 baud, 8 bytes per frame, open-collector

### Possible Issues Reported with Sony NXCAM Cameras

**From DVInfo Forum (NX70, similar platform):**
- Some Manfrotto LANC controllers didn't work while Libec controllers did
- Power was present (LED lit) but commands not executed
- Suggested causes:
  - Controller not fully "to spec"
  - Menu settings (though NX70's "remote" menu was for wireless, not LANC)

**Source:** [DVInfo - Manfrotto LANC Problem](https://www.dvinfo.net/forum/sony-nxcam-avchd-camcorders/507430-manfrotto-lanc-problem-2.html)

### LANC Command Codes (Relevant to MC2500)

**Byte 0 (Device/Sub-command):**
- `0x18` (0001 1000) = Normal command to VTR or video camera
- `0x28` (0010 1000) = Special command to video camera

**Byte 1 - Normal Commands (with Byte 0 = 0x18):**
- `0x33` = Start/Stop recording
- `0x30` = Stop
- `0x32` = Pause
- `0x34` = Play
- `0x36` = Rewind
- `0x38` = Fast Forward
- `0x3A` = Record
- `0x69` = Rec Review

**Byte 1 - Camera Commands (with Byte 0 = 0x28):**
- `0x35` = Zoom Tele slow
- `0x37` = Zoom Wide slow  
- `0x39` = Zoom Tele fast
- `0x3B` = Zoom Wide fast
- `0x00-0x0E` = Variable speed Zoom Tele (8 speeds)
- `0x10-0x1E` = Variable speed Zoom Wide (8 speeds)
- `0x41` = Auto-Focus on/off
- `0x45` = Focus manual far
- `0x47` = Focus manual near
- `0xAF` = Iris auto

**Source:** [Boehmel.de - Complete LANC Command Reference](http://www.boehmel.de/lanc.htm)

### Service Manual Reference

The HXR-MC2500 Service Manual (Page 114) references:
> "RN4984FE LANC JACK DETECT"

This suggests the camera has dedicated LANC detection circuitry.

**Source:** [ManualsLib - MC2500 Service Manual Page 114](https://manualslib.com/manual/2054656/Sony-Hxr-Mc2500.html?page=114)

## 7. Troubleshooting Notes

### If LANC Commands Are Ignored

1. **Verify electrical connection:**
   - Power LED on remote should light (camera provides 5-8V)
   - Measure voltage between Ring and Sleeve (~5-8V expected)

2. **Command timing:**
   - Commands must be sent for 3-4 consecutive frames
   - Frame timing: 16.6ms (NTSC) or 20ms (PAL)

3. **Byte 0 selection:**
   - Use `0x18` for VTR commands (start/stop, play, etc.)
   - Use `0x28` for camera-specific commands (zoom, focus)

4. **Check AODELAN notes:**
   - Some functions require pressing camera buttons first
   - IRIS: "Needed to press IRIS Auto/Man button on camcorder first"
   - White Balance: "Needed to press WHT BAL button on camcorder first"

5. **Model-specific quirks:**
   - Some newer cameras only respond to specific zoom codes
   - Codes `0x35/0x37/0x39/0x3B` "work on all cameras since approx. 1996"
